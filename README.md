# 🏆 Digital Heroes - Golf Performance & Charity Platform

A modern, premium full-stack web platform where golf performance fuels global charity impact.

## 🚀 Technical Highlights
- **Architecture:** Monorepo with React (Vite) and Node.js (Express).
- **Database:** PostgreSQL with Prisma ORM.
- **Security:** Triple-layer Access Gateways (Identity, Membership, and Privilege).
- **Business Logic:** Atomic "Top 5" score management and algorithmic prize draw distribution.
